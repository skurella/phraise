## Approach

One approach, `spikes/2026-09-27-github-storage-ghapi/`: bash scripts over `gh api`, because every gate is a sequence of HTTP calls and measuring headers is the point. No npm dependencies. The owner's `gh` keyring login supplies the token; scripts never read it.

A single library `lib.sh` is the only path to GitHub writes. It enforces the charter's safety rules in code:

- repository fixed to `skurella/phraise`;
- write methods allowed only on `repos/skurella/phraise/git/{blobs,trees,commits,refs}` and GraphQL `createCommitOnBranch`;
- every ref touched must be under `refs/phraise-spike/` or `refs/heads/spike-scratch/github-storage-*`, checked on the URL and on the JSON body;
- a persistent write counter with a hard cap of 300, and at least 1.1 s between writes, serial;
- any 403 or 429 on any call writes a STOP file; every later call refuses to run;
- evidence recorded per call as JSON lines: gate, method, path, status, duration, rate-limit headers, ETag. Never request headers, never the token.
