## Shape of the application

One spike directory, `spikes/2026-09-27-web-editor-tiptap/`, one approach.

| Part | What | Origin |
|---|---|---|
| `src/model/` | Spike 1's schema (with spike 5's `toDOM`/`parseDOM`), parser, serializer, style, compare, Yjs codec | copied from `origin/spike/2026-09-27-collab-stack` at `eeb3fe2`, `spikes/2026-09-27-collab-stack-yjs13-hocuspocus/src/` (itself spike 1 at `1e1f4a6`) |
| `src/collab/` | The two Yjs 13 workaround plugins, their Tiptap wrapper, the schema-to-Tiptap converter and `checkSchemaEquivalence` | copied from the same spike 5 directory |
| `server/` | One Node process: Hocuspocus 4.7 relay with SQLite, seeding `file:<relpath>` documents from a seeds directory through the codec, and a static server for the built page. Binds 127.0.0.1 only | spike 5's `relay.ts`, trimmed (no `plain:` or `rebase:` kinds) |
| `web/` | Vite-built vanilla TypeScript page: Tiptap 3 editor on the converted schema, Collaboration, CollaborationCaret, workarounds, a Markdown panel, later comments, source-block views, offline | new |
| `e2e/` | Playwright tests. Each test title starts with its gate letter in brackets, e.g. `[A] split and join`. A custom reporter groups results by gate and prints a table | new |
| `test/` | Vitest unit tests. `npm test` runs them | new |

Key choices, recorded as decisions in the findings doc:

- **No StarterKit.** Every node and mark comes from spike 1's schema through the converter, so the editor schema is spike 1's by construction. Editing behaviour (shortcuts, input rules, list indent, table navigation, paste, copy) is added as schema-free `Extension`s. A unit test runs `checkSchemaEquivalence` and fails if any extension adds a node or mark.
- **Serialize through spike 1's schema instance.** The page converts the editor document to spike 1's schema (`Node.fromJSON(schema, doc.toJSON())`) before `serializeDoc`, so no node-type identity comparisons cross schema instances. Its cost is measured in gate K.
- **Block `src` on split.** A block created by splitting or by Enter must not inherit the original `src`; it gets `src: null` so it re-serializes. Verified by gate A's byte checks either way; the serializer's verification is the safety net.
- **Test hook.** The page exposes `window.phraise` with `markdown()` (serialize now), `editor`, and small helpers, for tests only. Tests still drive all edits through the real keyboard, mouse and clipboard.
- **Ports.** Playwright's server fixture uses 4400 to 4449. `npm start` uses 4480 (page) and 4481 (relay) by default. Nothing binds outside 127.0.0.1.
- **Playwright browsers** in `spikes/2026-09-27-web-editor-tiptap/.pw-browsers/`, git-ignored, via `PLAYWRIGHT_BROWSERS_PATH` set in every npm script.
- **Offline** is a real offline mode: y-indexeddb for the document and a service worker caching the app shell, tested with `context.setOffline(true)` and a reload. If the service worker proves infeasible, the fallback is "relay unreachable, page server up", reported as such.

## Commands (target)

- `npm ci && npm run setup` — installs the Playwright browsers into the spike's cache and fetches the corpus files the gates need.
- `npm test` — unit tests.
- `npm run gates` — builds the page, runs every Playwright gate, prints the gate table and writes `results/gates.md` and `results/gates.json`.
- `npm start` — builds if needed, starts relay and page on 127.0.0.1, seeds from `examples/` (copied to a temporary directory), prints the address to open.
